🚀 Kartik Agarwal – Portfolio Website

A modern, responsive developer portfolio website built using React + Vite + Tailwind CSS + Framer Motion, showcasing projects, skills, and a fully functional contact form powered by EmailJS.

---

🌐 Live Demo

Temporary Live Link (Vercel):  
https://myportfolio-fjvblp7ln-kartikcc123s-projects.vercel.app  

> Custom domain setup is in progress.

---

✨ Features

- ⚡ Fast performance with Vite
- 🎨 Modern UI using Tailwind CSS
- 🎬 Smooth animations with Framer Motion
- 📱 Fully responsive design
- 🧠 Clean component-based structure
- 📩 Working Contact Form (EmailJS)
- 🖼️ Images served from `public/` folder
- 📄 Resume PDF accessible via button
- 🔒 Secure environment variables

🛠️ Tech Stack

- Frontend: React, Vite
- Styling: Tailwind CSS
- Animations: Framer Motion
- Email: EmailJS
- Deployment: Vercel / Netlify
- Version Control: Git & GitHub
